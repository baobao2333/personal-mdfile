# 需求翻译官 · clarify-intent

将口语需求和模糊感受转成准确概念与可检查的结果，让用户表达目标、判断效果，由助手负责概念识别、查证和理解校准。

当前版本：**1.1.0**。覆盖：编程、软件交互、游戏机制，以及 Suno 音乐、imagegen 图像等创作与提示词调整。

## 使用

技能主体是 [SKILL.md](SKILL.md)。将 `codex-skills/clarify-intent/` 目录导入支持目录式 Skill 的工具；具体导入方式以所用工具为准。

调用示例：

> 使用 $clarify-intent 帮我说清这个需求：我想要……，但不知道该怎么准确描述。

流程按需求复杂度调整：先查已有信息，识别候选概念，用具体行为或效果对照，只追问关键分歧，再按照本轮请求推进。

## 创作场景

优先比较参考图、音频片段或小样，明确“改什么／保留什么／怎样判断”。生成后核对实际结果；提示词写清楚不等于模型已做到。无法检查图像或音频时，明确标为未验证。

## 版本管理

- `VERSION` 记录当前版本；每个功能版本单独提交，提交历史可查看差异和恢复旧版。
- `releases/clarify-intent-vX.Y.Z.md` 保存该版完整技能；内容与对应版本的 `SKILL.md` 一致。
- `versions/clarify-intent-vX.Y.Z` 是对应版本的快照分支，按约定不再移动；后续修正创建新版本。
- 修正措辞、示例或不改变既定工作方式的问题，增加补丁号。
- 兼容现有用法地增加场景或能力，增加次版本号。
- 改变既有使用方式或关键行为约定，增加主版本号。
- 每次修改同时更新 `VERSION`、`CHANGELOG.md` 和版本导出，再建立独立提交与快照分支。
- 本仓库记录独立的发布快照，不会自动同步已安装的个人技能；后续更新需显式导出并提交。

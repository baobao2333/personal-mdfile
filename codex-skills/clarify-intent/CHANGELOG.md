# 变更记录

版本号在本次 GitHub 归档时建立；下面的日期记录功能版本形成时间，提交时间记录实际归档时间。

## 1.1.0 — 2026-09-21

- 扩展触发描述、界面说明与默认提示语，覆盖 Suno 音乐、imagegen 图像等创作和提示词调整。
- 优先用参考图、音频片段或小样校准，明确借鉴的特征及对照变量。
- 明确“改什么／保留什么／怎样判断”，保留用户对主观感受的判断。
- 区分创作意图、提示词或参数要求与实际生成结果。
- 要求生成后实际回看或回听，逐项核对改动与保留项；未能检查的部分标为未验证。
- 针对实际偏差迭代；用户仅要求提示词时，不擅自生成作品。

验证记录：完成格式与元数据检查，并通过音乐、图像两个场景的对话流程验证。本次验证没有实际生成或试听媒体作品。

## 1.0.0 — 2026-09-20

- 发布编程、软件交互与游戏机制的需求翻译流程。
- 将口语目标对应到准确概念，以具体行为对照校准理解。
- 默认每轮只追问最影响结果的一个问题，保留挑错与最小修正建议。
- 将澄清结果压缩为可实现、可检查的约定；明确需求直接执行。
- 整理可复用的需求表达。

验证记录：原始版本完成格式检查，并进行术语识别、导出需求澄清及筛选条件保存三个独立场景的流程验证。场景验证不代表穷尽所有需求类型。

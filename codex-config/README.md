# Codex 个人配置

更新日期：2026-10-12。

## 文件

- `AGENTS.md`：完整交付、关键条件取证、简洁答复、任务分工及授权保护原则。
- `gpt-base-instructions.md`：基础工程、交互和输出要求。
- `sol-worker.config.toml`：Sol 的任务级配置与执行要求。
- `luna-worker.config.toml`：Luna 的任务级配置与执行要求。
- `config.example.toml`：模型、提示词加载和 worker 角色的最小配置示例。

## 使用

将四份提示词文件放入自己的 `$CODEX_HOME`（通常为用户目录下的 `.codex`）。把示例中的 `model_instructions_file` 改为实际绝对路径，再将所需设置合并到现有 `config.toml`。新启动的会话加载更新后的配置。

示例保留模型和角色设置；本机通知命令、项目路径、MCP 服务、设备标识、运行状态和私人 endpoint 留在各自机器的配置中。

# personal mdfile

This repository contains sanitized personal multi-agent architectures, skill folders, and agent instruction templates prepared for public sharing.

## Folders

- [`agy-forge-architecture`](agy-forge-architecture/README.md) (18 files, 5 Markdown): AGY + Forge multi-model coding orchestration, non-blocking Sol->Neon (`xhigh`) concurrency scheduler, orthogonal L1 review, and Carbon pragmatic business arbiter.
- [`codex-config`](codex-config/README.md) (6 files, 3 Markdown): personal Codex instructions, worker configurations, and a minimal sanitized config example.
- `codex-skills` (118 files, 64 Markdown): personal Codex skill folders.
- [`growth-agents`](growth-agents/README.md) (7 files, 7 Markdown): file-based Growth app agent instructions.
- `harmonyvoice-project-skills` (12 files, 6 Markdown): project-specific HarmonyVoice skill folders.
- [`image-split-agent`](image-split-agent/README.md) (3 files, 3 Markdown): image decomposition agent workspace instructions.
- `openclaw-workspace-agents` (8 files, 8 Markdown): agent instruction files from the OpenClaw workspace.
- `openclaw-workspace-skills` (187 files, 53 Markdown): skill folders from the OpenClaw workspace.
- `prd-assistant-agent` (1 files, 1 Markdown): PRD generation agent instructions for the PRD assistant workspace.

Total packaged files: 360 folder files plus 3 top-level files.
Total Markdown files inside folders: 150.

## Packaging

Architecture and skill folders are synced as complete, self-contained subfolders including executable workflows, offline verification suites, `references/`, `scripts/`, `assets/`, metadata, and license files. Build caches, task logs, worktrees, dependency folders, VCS metadata, and private business configs are excluded.

## Sanitization

All packaged files are scanned and rewritten to strip sensitive or private patterns, including API keys, bearer tokens, cloud/VCS tokens, corporate/personal email addresses, local machine user paths, internal domain names, and business-specific identifiers.
